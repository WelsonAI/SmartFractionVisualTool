# Smart Fraction Visual Tool

An interactive visual learning tool based on SJKC Year 3 Mathematics Jilid 1.

## Learning modes

- Understand a fraction as part of a group
- Discover equivalent fractions with aligned fraction bars
- Connect improper fractions and mixed numbers visually
- Link fractions, decimals and percentages with a 100-square grid

The tool supports Bahasa Melayu, Chinese, and English. It uses visual manipulation rather than reading drills, and works with mouse, keyboard, or touch on desktop and mobile browsers.

## Run locally

Open `index.html` in a modern browser. No installation or build step is required.
